## 4. 已知坑（血泪，别重踩）

1. **本机文件守卫禁改写「已存在文件」**：C:/E: 都禁（D: 放行）。cargo 的 `.cargo-*-lock`/`.fingerprint/*/invoked.timestamp`、`Cargo.lock`、`dist/`、`.git/index`、`COMMIT_EDITMSG`、`.git/logs/HEAD` 全可能 EPERM；新文件可写。绕过：构建用 `CARGO_TARGET_DIR=D:/vv-target-rel`；删锁/指纹用 PowerShell `[System.IO.File]::Delete`；提交用 `git write-tree` + `git commit-tree -F <D:/msg>` + `git -c core.logAllRefUpdates=false update-ref HEAD <sha>`。
2. **生产编译必须带 `tauri/custom-protocol`**。上一版漏了，装上去变成「开发模式」exe，窗口里是 `http://localhost:1421` Edge 错误页。正确：`cargo build --release --features tauri/custom-protocol`。这次已确认窗口渲染的是应用界面。
3. **`lzma-sys` 的 `lib.exe` 归档必崩**（1114/LNK1104，同一次构建 sqlite/bzip2 正常）→ `zip = { default-features = false, features = [...] }` 去掉 `lzma`/`xz`。NSIS 打包阶段也撞守卫，**本次未生成安装包**，直接覆盖 exe。
4. **cargo package cache 锁**：曾有 PID 115496 的 rustc 卡住占锁，`Stop-Process -Force` 也被拒绝访问；等它自己退出后增量构建继续（本次 4 分钟编完）。别反复杀，先看 `Get-CimInstance Win32_Process -Filter "Name='rustc.exe'"`。
5. **CDP 9222 被 WorkBuddy 自己占了**，`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` 验不到影匣；换 9333 也没起来。要可视化确认就用一次性截图脚本（用完删），或靠管理员手动看。
6. **更新装机后不要自动启动应用**（管理员新规矩）。需要诊断才临时启动，看完关掉。
7. 旧坑仍有效：E: 盘在 Git Bash 跑 git 可能 SIGTERM → 用 PowerShell；hooks 必须放在 App 早退之前；扫描别持全局锁；新增子进程照抄 `proc.rs` 的 `CREATE_NO_WINDOW`。
